\# Universal Recommendation System



A content-based recommendation system using Sentence Transformers and FAISS.



\## Features



\- Movie recommendations

\- Product recommendations

\- Food recommendations

\- Clothing recommendations

\- Semantic search using embeddings



\## Technologies



\- Python

\- FAISS

\- Sentence Transformers

\- Pandas

\- NumPy



\## Run



python assistant.py

## Datasets

The original datasets and FAISS indexes are not included because they exceed GitHub size limits.

python src/building_embeddings_faiss.py
